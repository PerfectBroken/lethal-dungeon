# 0.8/R15 厚度与转角专项审阅

用户反馈：主岩体从前至后近似等厚，正面到侧面过渡不自然。旧0.55–0.73m的小扰动不足以产生可辨认的体量变化，不能以“参数不是常数”判断自然。

ST021先加实际多截面厚差检查，旧模型失败（variable-rock-red.txt）。保留内侧凹穴面，外侧厚度按纵深与高度共同塑形：前缘薄，中腰局部厚，后端收回母岩；实际多截面厚差超过0.35m，最低/最高厚度断言0.3–1.2m。正侧面交界从邻接扫描区域延续UV，边缘UV与主体相同；去除异色材质乘色，修正封边三角绕序，跨UV缝平滑法线。

实际全景和左岩壁对照近景可见中腰鼓出、前缘收薄，异色封边明显减弱；转角处仍有局部纹理压缩拉伸、顶部轮廓和概念不完全一致。内部单体80/100：体量27/30，轮廓与空间24/30，转角材质21/30，保留细节8/10。非用户已认可。

18项测试通过，包含原通路、滴水、凹穴封闭、骨堆可见性和石笋位置；构建结果见variable-rock-build.txt。没有用测试分数替代视觉评分。
