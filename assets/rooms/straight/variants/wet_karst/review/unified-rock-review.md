# R18 / 0.11 五项整体修正

对应用户截图，不把消除旧拉丝视为整体合格。先增加ST025/026规范与失败测试，再制作。

1. 补丁：主岩体取消buttressFracture独立材质，和西墙/扫描侧墙共同采用世界空间三向PBR，烘焙到完整GLB，不依赖预览shader。正侧面的宽色带消除。初轮烘焙原点错误产生三角拼块，真实渲染发现后修正GLB UV原点与法线TBN方向，加入导出回归检查。
2. 厚板折痕：主岩体跨UV缝联合圆顺8轮，保留厚度/凹穴/前低后高；颜色连续使原封边不再成为折板轮廓。整体与俯视都复核，仍保留概念方向的倾斜岩体，不声称自然洞穴扫描复原。
3. 接地：岩脚低位埋入地面，地面生成与前缘衔接的沉积坡；初轮近景仍有宽黑边，继续增加交接并将过宽AO范围缩小至0.16/0.10m。最终岩脚为薄接触线而非悬着的黑色厚底。没有取消阴影来绕过问题。
4. 西墙：扫描边缘在南北端逐渐收回背部母岩，材质投影统一，原下半灰棕切边和显著薄片边弱化。原截图左边外侧也包含预览剖切边界，不将剖切展示本身误称物理裂缝。
5. 摆件感：三根短石笋改非共线错落布局，补低矮沉积根部；碎石四类形态都压成片状断裂比例、减少直立翻转，移除圆石抱团视觉。

实际检查：左岩壁对照（与用户截图对应）、岩脚近景、俯视；检查连续材质、薄边、接地、骨堆与水潭位置。已知的成片贴图拉丝和补丁未作为待改项交付。整体仍是示例房审阅资产，不给无依据高分，不标记用户认可。

26项测试通过，Vite构建通过，证据unified-rock-green.txt、unified-rock-build.txt。源和GLB版本0.11；292338三角形、16网格、13内嵌图片。新增8K图集让GLB约82MB，当前未做移动端压缩/LOD，不把单房审阅通过当真机性能验收。
