# 02 · 直通房 / 潮湿溶蚀洞穴

独立三维审阅资产。身份：straight / 直通房，变体 wet_karst。依据 ../lethal-dungeon/docs/art/straight/concept-v02.png。参考 ../cave-room-preview/MEMORY.md，不能覆盖第一房。

## 模块
- model/README.md：建模规范与接口；room-identity.json 保存关联；room.mjs 为可复现建模源。
- tests/README.md：真实几何、导出与水滴检查。
- main.mjs：实际 Three.js GLB 渲染、相机与滴水动画；灯光只作审阅，不导出。
- public/models/straight-wet-karst.glb：完整含纹理模型。
- evidence/REVIEW.md：固定视角视觉自查及评分，80 分为内部提交流程，不代表用户验收。

运行 npm run model 后 npm run dev（localhost:3001）；npm test 检查产物。npm run build 只编译预览，不会覆盖模型。依赖首次复用相邻预览 node_modules；移机后 npm install。无在线部署。

## 坐标与显示
导出坐标与配置一致（北+Z，东+X，米制）；配置的每单位为0.5米。为在右手系 Three.js 相机中显示图上的北上东右，网页对根节点做 X 镜像，并同步水滴位置。它是显示适配，不改资产坐标。引擎接入须明确坐标/绕序转换，不能直接照搬网页变换。

本版有16个类别网格、13张内嵌纹理；297458个三角形。动态滴水与波纹由网页依据GLB元数据播放，GLB本身不含完整动画剪辑。审阅模型未制作LOD、团结碰撞/导航或真机性能验证。

当前为R27/0.20：共27个编号预览版本（含R1–R7内部试做），正式资产0.1–0.20共20版。R22获用户“可以用了”的反馈；R27蜘蛛网单体获95分，不代表整房95分或引擎集成完成。完整错误复盘与后续执行规则见 [MEMORY.md](MEMORY.md)。修改几何或材质后必须重新审阅，不能沿用旧分数；下方为逐版历史，旧“当前/待审阅”状态以最新记录为准。

本轮0.2：左岩壁长度5.7m，倾斜岩板与西墙之间保留下方凹穴；清除原65块环状岩脚碎石，使用独立种子的四类断裂碎石，分四处崩落簇布置。新增“左侧凹穴”观察视角。

0.3 / R10：左侧扫描岩面补出约0.55–0.73m厚度与独立材质断面；平顺扫描边界的小锯齿，保留5–6m长度和后侧凹穴。生成函数见 model/rock-volume.mjs，规范ST012；当前仍待用户美术审阅。

0.4 / R11：依据用户对0.3的20分反馈，主岩体前端向西弯回，上下采用不同曲率；圆钝边缘与局部抬升下缘保留凹穴口。仍待用户美术审阅。

0.5 / R12（当前方向）：入口在南-Z，后方在北+Z。岩体前方展开、向后靠西墙收束封闭，骸骨放在凹穴深处；旧0.4前端收回的解释错误。相应规范ST013–015已纠正。

0.6 / R13：左岩壁连续落地，岩冠由前低后高逐渐接顶；前断面增加几何层理，左贯穿柱改短石笋。左岩壁单项内部80/100（不代表整房或用户验收），逐项扣分见 evidence/REVIEW.md。

0.7/R14：西墙扫描层和底层补背面与端部；左岩脚只留3根前外侧石笋，移除内侧石笋簇；碎石使用细分侵蚀几何、连续UV和平滑法线。模型源新增 model/fractured-stone.mjs，规范ST018–020。主岩体保留R13，细节待用户验收。

0.8/R15：主岩体厚度随纵深和高度变化，前缘收薄、中腰鼓起、后部收束；正侧面交界使用相连扫描UV并平滑法线。旧近等厚ST012由ST021替代。当前仍待用户审阅。

0.9/R16：按ST022缩短入口端，岩壁厚度与内侧净空同量级；骨堆前移到凹穴口内侧，补入场眼高检查。结构评分规则与审阅见 evidence/proportion-review.md；旧R15达标结论撤回。

0.10/R17：前断面改为米制UV及可平铺岩石PBR，修复折返拉丝；三根石笋移到岩体前外侧并按完整包络检查。真实近景/侧面复查记录：evidence/uv-contact-review.md。

0.11/R18：取消独立封边材质，主岩体与侧墙世界空间PBR烘焙到GLB；联合圆顺几何、收回墙面边缘、沉积地形连接岩脚，石笋错落并增加根部，碎石改片状。新增model/bake-rock.mjs；当前GLB约82MB，烘焙图集8K，是审阅资产，不能直接当移动端成品。详见evidence/unified-rock-review.md。

0.12/R19：按用户新增思路制作五段连续弧面（外、正外、前、正内、内），正面略向外凸；骸骨向内退0.37m，入口仅部分可见。石笋、地面沉积及碎石联动清理，规范ST027/028，记录evidence/five-face-review.md。用户75分针对R18，不自动转移为本版评分。

0.13/R20：撤回R19五面已完成的结论，收回两侧肩部接点、加宽真实斜向过渡面；新增“过渡面侧视”。全高度联查石笋、接地与半遮掩，记录evidence/broad-shoulder-review.md。

R21/0.14：用户对R20/0.13左岩壁明确给85分，保存为已认可的几何基准。本轮仅岩壁烘焙后线性RGB乘色[0.78,0.80,0.83]及骸骨北侧独立碎石堆；不调整全局补光、骨色或骨位置。首次近景发现石堆像人工叠石，减少上层堆叠并错落倾斜。新细节等待审阅，不把85分扩展为整房验收。记录evidence/mood-talus-review.md。

R22/0.15：用户认可R21细节，指出室内洞顶过渡像叠板。根因是旧roofRim有上下板及竖边，与独立平顶相交；取消这些叠层，中央顶面与两侧连续拱落共用高度场、法线及米制UV，仅为剖顶显示而分网格。钟乳石根部跟随局部顶面，尖端和滴水落点保留。以后检查必须包含完整洞顶的玩家眼高，不能只看剖顶全景。记录evidence/ceiling-review.md。

## 封墙审阅（R22）
用户要求检查被示例门洞占据的岩面。运行 `node model/export.mjs --closed-walls` 单独生成 `public/models/straight-wet-karst-closed-walls.glb` 及 `model-info-closed-walls.json`。网页当前加载该文件，默认室内视角；原开门版GLB继续保留，`npm run model`仍生成开门版。封墙版是美术检查用途，尚非可变门位模块。当前服务端口3002（旧3001进程未识别新增公共资源，且不可终止）。

R23/0.16：蛛网换为灰白半透明丝质（opacity 0.48，roughness 0.78，非金属，不写深度），支撑丝和捕获丝粗细分开，网眼间距与破损独立随机，局部松弛下垂。网上下载的两份素材风格不合适，未采用，筛选记录见evidence/rejected-assets/README.md。封墙审阅图集4K、其他贴图限制2K以降低内存；原始素材和默认导出仍保留原分辨率。GLB导入网页需恢复透明材质depthWrite=false（glTF不表达该字段）。

R24/0.17：用户否定R23墙中央扇形蛛网。根本失误是缺少合理位置与跨面支撑，不能靠换材质、整体平移和长连接丝修复。两张旧网全部撤掉，改为东北上方角落一处小型非放射积网，锚点落在东/北实际岩面，轻微下垂和断丝。首轮像吊兜，降低下垂后复查；未自行判为用户认可。

R25/0.18：用户认可R24角落位置，指定改为平面圆网；替换三角积网，近圆轮廓、放射丝、连续螺旋捕获丝及三个跨面牵引锚点。保留角落区域，真实近景复查。此前下载的是不适用的2D素材，本版为新建几何，不能说复用了已下载圆网3D模型。

R26/0.19：按用户实拍参考，圆网牵引丝必须与网内放射丝共线，至少6根。现在从24根现有放射丝中选择8个可真实落到岩面的方向，沿原方向延伸到首个岩面交点；保存webTethers供共线/数量/接触回归。保留角落和圆网主体。

R27/0.20：牵引丝最低高度筛选错误地删掉下方支撑。今后约束主体仍在上方角落，不把主体的包围盒高度规则套到延长牵引丝。四象限各2根、保持共线和真实岩面接触；网外两道横向连接加固。用户要求覆盖方向，不能仅检查总数够8根。

2026-09-09 用户验收：R27/0.20 蜘蛛网单体获95分，已认可。后续复用基准：角落悬挂的平面圆网；放射丝与螺旋捕获丝；左上/左下/右上/右下各2根共线外延支撑丝，实际岩面落点；网外两道横向加固丝；半透明丝质。保护此结构，不能退回墙中央扇网或三角渔网。评分仅限蛛网，不代表整房95分。
