# 建模规范
CL001 身份来自正式配置corner_left，包络8×8×4米，北+Z。
CL002 圆腔与南/西直通喉道构成连续空腔，仅南/西开口；西轴严格-X，北东封死。示例接口2米宽3米高，出界轴线无遮挡。
CL003 主体为有厚度岩壳；圆润不规则腔体、连续拱顶、真实接地，不做鹅卵石墙或独立平盖。
CL004 中央和南到西路径至少1.2米宽、2米高净空；所有几何坐标保持占用包络，地面连续可行走。
CL005 地质变化用低频体积、方向性层理、小尺度侵蚀；贴图使用真实已有CC0 PBR，连续投影，导出不得遗漏。
CL006 先审主体，再地面，再稀疏边缘碎石与短钟乳石；不得随机堵路。细节含独立形态与岩面接触。
CL007 确定性生成，几何有限值、有效三角形、法线；导出包含身份，模型与预览相同几何。预算30万三角形以内，非真机结论。
CL008 每个单体内部审阅≥85再推进；严重穿模、破面、错误朝向、纹理拉伸阻断交付。证据必须来自实际3D。

CL009 地面以连续高度混合泥土/裸岩，湿斑只影响局部色调粗糙度，不增水潭或规则波纹。地面单体先审至85分，再放边缘物件。
CL010 边缘细节：仅稀疏非等距的崩落碎石与少数短钟乳石；用实际岩面射线确定落点和根部，根部小量嵌入是连接，不允许主体露出截面或横穿墙体。物体不得位于中央通路或接口净空。

CL011 以入口朝北的左右构图为准：左侧一长三短、右侧三短，共7根；中央|X|<0.9m留空。取代旧CL010的数量建议，根部仍贴合真实洞顶。
CL012 正前方北墙左上有约2m宽的嵌入巨石，连续融合母岩，不能独立悬浮；不侵入南西接口。
CL013 墙角碎石增加至100–170块，多尺寸崩落簇和宽窄不同的碎石裙边，中央及洞口净空保留。数量测试不能代替可见密度审阅。

CL014 普通滴水型钟乳石主轴沿世界-Y重力方向，不跟随斜顶法线，不随机倾斜。根环贴合斜顶，截面、长度、粗细可不规则；尖端必须位于根部轴心正下方。以实际尖端顶点检验，不只检查倾斜参数。参考：https://www.nps.gov/subjects/caves/speleothems.htm 。

CL015 六根短钟乳石长度0.42–0.56米，长石保持0.78米；短石有可读的锥体长度，不只剩尖端。保持CL014竖直主轴与2米净空。
CL016 门位兼容边界：当前field写死南/西居中喉道，尚未消费所选socket。base-rooms.json的corner_left也仅有居中south/west，requiredSockets要求二者；allowedRotations不是沿墙随机偏移。圆腔可扩展连接通道，但必须新增目录候选/选择策略、清单真实门位、模型对应封开口与完整通路校验；不得以旋转或身份关联声称随机门位完成。

CL017 随机门升级：从正式base-rooms.json读取corner_left各socket的position、tangentOffsets及size，0.5m转米；buildRoom({doors:{south:offset,west:offset}})仅接受合法偏移，null表示封闭该侧作检查。偏移以配置单位传入，不允许自由坐标。南西墙允许趋于平直，整条候选范围有足够通路，不改北东封墙。导出消费服务器manifest指定实例的SocketOffsets，同一份选择写入GLB extras，不能客户端再次随机。九种组合逐门射线/净空和封墙验证。

CL018 V04已获用户认可：西北为较宽斜向岩肩、西南为紧凑不对称圆弧、东南为下展上收的接顶岩褶。角部连续体积相接，不用独立石柱遮挡，不做等半径机械倒角。岩肩局限于墙端，南西候选门位中段和CL017九组合净空必须保留；上下截面变化，轮廓及纹理连续。

CL019 正对入口的北墙必须有真实体积的弯曲倾斜层理：至少四条可从入口读出的层缘与凹槽，层间距、凸出深度有所变化，并向侧壁、地面及洞顶渐隐。不可用增强贴图或整齐重复的平行条带替代；嵌入巨石仍融合母岩，CL017门位通路保持。以北墙实际场表面采样检查中尺度起伏，并以入口实景检验构图。

CL020 门旁墙面不能是平整箱体：候选墙段需连续低频岩面起伏与较细的侵蚀层理，选定门洞净空最后裁切。泥土贴图与岩石一样使用按表面方向混合的投影，不能仅用XZ俯视投影到竖墙造成纵向拖纹。九种门位仍须通过。

CL021 风格统一以主轮廓为先：南西墙段必须与圆腔共享鼓出、凹陷及顶部内收的岩体尺度，不能用几厘米噪声证明自然。无门样本的墙面垂直剖面至少有0.4m深度变化，实际门旁视角与圆腔对照；最终开门净空仍优先，变化不能靠独立贴墙石块堆砌。

CL022 碎石放置后按实际包围盒与所选门位通路检测相交，不能仅检查中心点或固定墙边距离。碰撞回归失败先输出命中物体及位置，再修改；不得猜测是墙体或门角。

CL023 R22用户要求南西门墙起伏进一步加大，整体体积起伏按R21的1.45倍试制，仍须全部门位回归。当前网页加载的是导出阶段按服务器清单开洞的GLB，浏览器没有实时挖洞；不得将参数化离线生成声称为团结运行时开洞能力。

CL024 用户偏好环绕岩体的嵌套弧圈层理，替代R19横向叠层。北墙层缘采用偏心、略扭曲的椭圆弧，间距宽度不等，向顶底与侧壁融合，不做机械同心圆或独立悬浮环。仍保留左上嵌入岩与门位净空。

CL025 用户将R23四道环层简化为两道宽弧，保留偏心与不规则变化，中央岩面留白，不新增小内圈。

CL026 R25细化分支保留approved/r24的已验收快照。原有大石簇加2–7cm级碎石填缝、局部堆叠和外缘散落；用真实表面射线承托，不悬空、不侵入所选门通路。钟乳石保持7根及重力轴，轮廓增加不等距沉积肩、竖向沟纹与瘤状凸起，避免光滑圆锥或等距车削环。此次整体品质未经用户验收，不继承R24的85分。

CL027 R26：碎石簇下仅补少量贴地泥土，边缘埋入地面，厚度不超过3cm、不能盖住碎石；钟乳石横向缩至R25的80%，保留长度、垂直轴和沉积肩。泥土使用已有brown_mud_02材质。

CL028 R27取代CL026/027局部要求：删除额外泥土；较大碎石向墙脚收拢，细碎石减量，检查小石整个底面与支撑石的接触，不能只取中心高度再下沉。钟乳石7根中三根加长保留沉积肩（0.98/0.62/0.68m），其余四根保持原长并恢复平滑轮廓。重力主轴与门位净空仍必须通过。

CL029 钟乳石根部用连续扩大且贴合真实洞顶的沉积裙边连接，避免细柱插入屋顶。裙边外缘逐点射线贴合，不用水平圆盘，外沿薄薄埋入母岩；保留三长层纹四短平滑及尖端重力轴。
