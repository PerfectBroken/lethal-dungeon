# 房间逐物体建模与验收流程

来源：用户于2026-09-09认可直通房R13左岩壁达到80分，并要求此流程用于之后所有房间。该要求优先于旧的“整房完成后统一打分”流程。

1. **先拆分清单。** 对照已认可概念图及房型配置，列出房间内主要建模对象，例如主体岩壁、凹穴岩体、棚屋、石柱、水潭、骸骨组。按空间关系和依赖排序，记录对象总数、当前对象、版本、评分和用户认可状态。只为定位其他物体而设的占位体不算开始其正式建模。
2. **逐物体拆解参考。** 写清朝向及坐标、长宽高比例、轮廓曲线、落地和接顶、厚度、开口与封闭关系、材质层理、附属细节以及与相邻物体的接触。先判断主体形状与空隙是否正确，再看材质；不能用随机噪声、堆装饰或遮挡掩盖结构错误。
3. **先规范与必要测试，再建模。** 规范写入该模块README。可验证的尺寸、通路、厚度、封口、位置和遮挡先写测试；测试通过不计入美术分数。
4. **实际渲染，逐项对照修改。** 每轮修改后运行真实3D渲染，从概念对应角度、侧面、俯视和必要近景检查。记录仍可见的差异，修复后再看，不能只看代码或导出成功。移动物体后同时检查周围装饰、碰撞和遮挡；不得破坏已认可对象。
5. **单物体达到80分才推进。** 为当前对象先确定适用的评分项及权重，依据实际渲染逐项评分，记录扣分原因、版本和观察视角。低于80分继续修改当前对象，不进入下一个主要对象；不能临时改权重、忽略问题或用技术检查凑分。内部80分不等于用户认可；用户否定或低于80分的评价优先，回到当前对象修正。
6. **完成所有单体后再验整房。** 所有主要对象达到门槛后，再检查整体风格、比例、空间关系、通行、光照、滴水落点与性能。整房通过不能代替单体门槛；美术认可不等于引擎集成或真机验收。

## 当前认可范围

直通房 `straight / wet_karst`，模型0.6 / R13：**左侧主岩壁**由用户明确认可达到80分。保持该基准，未经新的反馈不要改回旧形态。该认可不自动扩展到其他物体或整间直通房；其他对象要按本流程独立检查与记录。

## 结构评分补充（R16用户反馈）
结构必须按相对关系打分，不能只验证“存在厚度、存在凹穴”。当前岩壁结构权重：实体厚度/负空间比例25、纵深起止/相邻地标20、入场视线20、曲率/正侧过渡15、落地接顶封口20。前三项任一明显错误时结构分上限59，单体不得判80；测试通过不加美术分。其他物体开始前按其语义制定相应权重。
概念图无法给出毫米级精确尺寸，须标注近似设计目标。本例厚度/内侧净空约0.8–1.4倍，岩壁前端与水潭后沿约齐。旧固定长度条款被新布局要求替代。骸骨必须从真实入口眼高可辨认，不能只用洞内特写或局部无遮挡样本代替。
R15结构达标结论撤回；R13历史用户认可保留为历史，不自动适用于后续修改。

## 明显缺陷不得交付（R17纠错）
严重纹理拉伸、可见穿模、悬空、错误遮挡是阻止交付的问题，不能仅记录扣分后提交，也不能以某个分项80绕过。发现后先修复，再实际运行检查同一处及邻近物体。扫描UV图集不可当平铺纹理；附属物检查完整体积而非中心点。
