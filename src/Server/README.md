# Server：权威房间服务端

## 用途与边界

对应技术架构中的Game.Server，负责权威房间运行。当前仅建立模块规范，尚未创建服务端程序集或部署服务器。

## 必须遵守的规范

- 已确认玩法以仓库docs中的需求规格为准；各模块先规范、再测试、再实现。
- 服务端掌握统一时间和游戏状态；客户端提交请求，不自行裁决全局结果。
- 编排模块通过接口协调子模块，不把地图算法、网络传输和客户端表现混写在一起。
- 引擎、网络、存储等外部能力不得反向进入纯规则Domain。

## 模块与依赖

- [ExpeditionStartup：探险启动编排](ExpeditionStartup/README.md)：从准备出发到全员统一进入探险的完整流程。
- 地图生成、地图验证、房间模拟等模块将在各自开发前建立规范；目前不创建空实现。

## 测试与执行

各模块README列出先行测试要求。当前没有Server测试项目或运行命令；现有Domain/Architecture测试通过不代表服务端已实现。

## AI修改约束与验证限制

不自行补定财宝、结算、加载超时或断线惩罚。服务端平台、导航和联机需要真实环境验证；本目录目前只有规范。
