# Domain

## 用途与边界

容纳纯游戏规则；目前只有BackpackLoad和WorldClock。需求来自相邻文档的需求规格第4、7节，研发约束见根README。子模块独立披露契约。

## 必须遵守的规范

| ID | 规范 |
|---|---|
| DOM-001 | 仅标准库，无包引用和跨项目引用；无UnityEngine、IO、网络、真实时钟依赖 |
| DOM-002 | 每个规则子模块有README，测试映射和限制可追溯 |
| DOM-003 | 使用netstandard2.1和C# 9，不因测试宿主为.NET 10而使用其专有API |

## 接口与依赖

只通过公开方法和只读快照暴露行为。没有资产、房间或网络状态。时钟由调用方注入，单个实例由服务端房间线程串行使用；多线程调度不在本模块内实现。

## 测试与执行

DOM-001～003由Architecture.Tests检查项目引用、程序集引用、目标框架、语言版本及关键文档。源文本检查只是补充防线，不能证明不存在所有反射或动态依赖。业务规则由Domain.Tests验证。命令见根README。

## AI修改约束

先修改目标子模块规范和测试，再实现。不得把待定玩法加入本程序集；不得直接获取客户端状态或操作持久化资产。

## 验证与已知限制

初始状态为规范阶段，实际执行结果见evidence。引擎导入尚未验证。
